Practice App Help

Study and recite the Amarakosha with audio playback, practice sets, and guided drilling.

Overview

The Amarakosha Practice App lets you work through the pādas of the Nāmaliṅgānuśāsana at your own pace. You can listen to reference audio, study word-by-word, and build custom practice playlists called Practice Sets.

The text is organised as: Kāṇḍa → Varga → Section → Pāda. There are 3 Kāṇḍas, 25 Vargas, 63 Sections, and 2,865 Pādas in total. Each Varga is a topical group (e.g. heavenly bodies, trees, animals); each Section is a semantic cluster within a Varga.

Home Screen

The home screen shows a resume card for your current position, three quick stats (total pādas, sections, vargas), and a list of all Kāṇḍas with pāda counts.

  • Tap Continue Practice to return to your last position, opening the Practice Set panel immediately if you had a set in progress.
  • Tap any Kāṇḍa row to go to the Browse screen for that Kāṇḍa.
  • The Browse screen lets you pick a Varga to enter the Practice screen.

Browsing the Text

The Practice screen has three areas:

  • Tree pane (left sidebar on desktop, slide-in overlay on mobile) — the full hierarchy of Kāṇḍas, Vargas, Sections, and Pādas.
  • Practice pane (centre) — the currently selected pāda, audio player, and word chips.
  • Practice Set panel (right sidebar on desktop, bottom sheet on mobile) — your curated playlist.

Tree pane

  • Tap a Kāṇḍa row to expand or collapse it.
  • Tap a Varga row to expand it and see its Sections.
  • Tap a Section to jump to its first Pāda.
  • When a Section is selected, its individual Pādas appear below it — tap any to go directly to it.
  • A small speaker icon next to a Pāda indicates audio is available for it.
  • A small dot (●) means Devanagari text is available.
Long-press a Section or Pāda in the tree to add it to your active Practice Set. A checkmark icon appears on items already in the set.

Practice pane

The practice pane shows the active pāda's Devanagari text in a highlighted box. The pāda's GRETIL reference (e.g. 1.1.11 A) appears inline before the text. A progress bar and "Pāda N of M · Section name" label at the top show your position within the current section.

Use the Prev and Next buttons below the pāda box to move linearly through the corpus. Navigation wraps across section and varga boundaries.

Context lines

You can display neighbouring pādas above and below the active one for context. Context pādas are shown in a smaller, dimmer style; tapping one navigates to it. The number of context lines is controlled in Display Settings.

Section and Varga headings appear automatically when the context window crosses a boundary, so you always know which section each pāda belongs to.

Audio Playback

The Audio card at the bottom of each pāda contains the full playback controls.

◀ ⏹ ▶ / ⏸ ▶ skip prev · stop · play/pause · skip next
0.5× 0.75× 1× 1.25× 1.5× playback speed
  • Play/Pause — starts or pauses audio for the current pāda.
  • Stop — stops playback and resets the progress bar.
  • Skip buttons — navigate to the previous or next pāda.
  • Speed chips (0.5× – 1.5×) — adjust playback rate without reloading.

Audio Sources

Above the progress bar is a row of chips for each available audio source:

Built-in Teacher A × + Import
  • Built-in — the reference recordings bundled with the app.
  • Named sets — teacher recordings imported from a ZIP file. Tap a chip to activate it; the × removes the set.
  • + Import — opens the import dialog (see Teacher Audio Sets).

If the active source has no recording for the current pāda, the app automatically falls back to the next available source.

Auto-advance

The Auto toggle (bottom-right of the audio card) makes the app automatically move to the next pāda and begin playing as soon as the current pāda finishes — useful for continuous listening without touching the screen.

Practice Sets

A Practice Set is a curated playlist of Sections and/or individual Pādas you want to drill. You can have multiple named sets, and they persist across sessions.

Adding items

  • Long-press a Section in the tree → adds all pādas in that section.
  • Long-press a Pāda in the tree → adds just that pāda.
  • Tap Add range (at the bottom of the set panel) → opens a picker to add pādas by Kāṇḍa / Varga / Section position.

Managing sets

On desktop, tap Set (N) in the nav bar to open the Practice Set panel. On mobile, tap the tray bar at the bottom of the screen.

The tab strip at the top of the panel shows all your named sets. Tap a tab to switch to it. Tap + to create a new set.

  • Long-press a set tab to rename it.
  • Tap the × on a tab to delete that set (kept as long as at least one set exists).
  • Drag items in the list to reorder them.
  • Tap × on an item row to remove it from the set.
  • Tap Clear to remove all items from the active set.

Playing a set

Tap Play Set to begin sequential playback through all items. Tap Stop Set (red) to end playback at any time.

While a set is playing, the practice pane switches to a playlist view: a scrollable list of every pāda in the set. The currently playing pāda is highlighted; the others appear in a smaller, muted style. The view auto-scrolls to keep the active pāda in view.

Depending on your Set context settings, the playlist also shows a few neighbouring pādas from the full corpus immediately before and after the active pāda — displayed even smaller and more muted to distinguish them from set items. This gives you reading context without cluttering the playlist.

PLAYLIST DURING SET PLAYBACK
… context pada (smaller, dimmer) …
1.1.4 A  active pāda text here
… context pada (smaller, dimmer) …
1.1.7 A  next set pāda

A Replay button re-plays the current pāda from the beginning without advancing. In step mode (see below), a Next → button appears to advance manually.

Tip: Set playback uses the currently active Audio Source. Switch to a teacher set before tapping Play Set to drill with the teacher's voice.

Guided Practice

Enable the Guided Practice toggle in the set panel to alternate between a model play and your own recitation for each pāda.

Teacher plays — cycles of model + student
Student recites — times per teacher play

For each pāda, the sequence is: model play at full volume, then the set number of student recitations at low volume, repeated for the set number of teacher cycles. For example, with Teacher plays = 2, Student recites = 2:

  1. Model (full volume)
  2. Student recitation (low volume)
  3. Student recitation (low volume)
  4. Model (full volume) — second cycle
  5. Student recitation (low volume)
  6. Student recitation (low volume)
  • Student volume — how quietly audio plays during student recitation slots (0–20%). At 0%, the audio is silent so you recite unaided.
  • Gap between recitations — pause in seconds inserted between consecutive student recitations within a cycle (0–5 s). Only shown when Student recites > 1.
  • Step through pādas — when on, playback pauses after each pāda's full repetition cycle and waits for you to tap Next → before moving on.
The Full Set stepper (visible in both normal and Guided mode) repeats the entire set N times. The total pāda-play count is shown below the steppers.

Teacher Audio Sets

A teacher can record pādas in the Recording Studio and export them as a ZIP file. You can import that ZIP as a named Audio Set.

Importing a ZIP

  1. In the Audio card, tap + Import.
  2. A dialog appears showing how many WAV recordings were found in the ZIP.
  3. Choose Create new set and enter a name (e.g. "Pandit Sharma"), or choose Update existing set to replace recordings in an already-imported set.
  4. Tap Import. The set appears immediately in the Source row.

Using a set

Tap the set's chip in the Source row to activate it. All playback — individual pādas and Practice Set — will use the teacher's recordings where available, falling back to Built-in for any pādas not covered by the import.

Removing a set

Activate the set, then tap the × that appears on its chip. This permanently deletes the imported recordings from the browser's storage.

Audio sets are stored in the browser using IndexedDB. They persist across sessions but are specific to this browser and device. To use a set on another device, import the ZIP there as well.

Recording Your Own Voice

The Recording Studio (accessible from the home screen) lets you record your own recitations pāda by pāda and export them as a ZIP file.

Recordings you make in the studio can then be re-imported as a named Audio Set so you can play back and compare your voice against the reference recordings. See Recording Studio Help for a full walkthrough.

Word Analysis

Where word data is available, a Words section appears below the pāda box. Tap the "Words N" heading to expand it.

Each word chip shows:

  • The Devanagari form of the word
  • A brief meaning or grammatical label
  • The IAST transliteration (italicised)

Long-press a word chip to open a detailed grammar sheet with the full analysis, stem form, and grammatical category.

Display Settings

Tap the ⊞ icon in the top-right of the nav bar to open Display Settings.

Text sizes

  • Sanskrit text size — size of Devanagari text in the pāda box (14–72).
  • UI text size — size of English labels, annotations, and section titles (11–22).
  • Navigation text size — size of text in the tree pane (10–20).

Context lines

  • Context lines before / after — neighbouring pādas shown above and below the active pāda while browsing (0–5 each). These are tappable to navigate.
  • Set context before / after — context pādas shown in the playlist view while a Practice Set is playing (0–5 each). These come from the full corpus and appear smaller and more muted than the set's own pādas.

Text weight & font

  • Text weight — choose Normal, Medium, Bold, or Heavy for UI labels.
  • Sanskrit font — switch between Tiro Devanagari Sanskrit (bundled, recommended) and Noto Serif Devanagari (via Google Fonts).

Themes

Four colour themes are available. Tap a circle swatch in Display Settings to switch instantly; the choice is saved across sessions.

  • Parchment — warm cream and terracotta. The default.
  • Night — dark warm background with amber accents. Easier on the eyes in low light.
  • Slate — cool grey-blue with steel-blue accents.
  • Minimal — clean white and light grey with indigo accents. A modern, undecorated look.

Mobile Tips

On small screens the layout adapts:

  • The tree pane is hidden by default. Tap Contents in the nav bar to open a full-screen slide-in tree. Tap outside it (or ×) to close.
  • The Practice Set panel becomes a bottom sheet. Tap the Practice Set tray bar at the bottom to open it.
  • Audio controls are slightly larger for easier tapping.
Install as an app: On Chrome or Safari, use Add to Home Screen (or Install in Chrome's address bar) to run the Practice App as a standalone app without browser chrome. It works offline once cached.
